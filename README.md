# The Constellation Guild Website

This project is a dark, cinematic astronomy club website for The Constellation Guild.

## Run locally

From the project root, start a simple local HTTP server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` — page structure and content
- `style.css` — full dark aesthetic styling and responsive layout
- `script.js` — lightweight tab switching and form interactions

## Notes

The homepage and about content are intentionally designed around a club-admin/owner workflow, as requested. The public-facing site is polished and ready to share, while the core home/about messaging can be updated by the club admin in source control or a future CMS layer.
